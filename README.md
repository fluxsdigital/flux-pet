# Flux Pet

Publicação Next.js da tela atual do projeto **Flux Pet Landing Page** no Google
Stitch (ID `7808829562387346976`).

## Executar e validar

Requer Node.js 20 ou superior.

```bash
npm install
npm run dev
npm run lint
npm run build
```

## Conteúdo publicado

- `/`: `flux_pet_gest_o_acolhedora_e_inteligente`, a única tela com exportação
  disponível no estado atual do Stitch.
- O HTML e os três assets visuais exportados são servidos localmente em
  `public/stitch` para preservar fielmente o design.
- Material Symbols e Plus Jakarta Sans são carregadas de arquivos locais; os
  nomes das ligaturas não ficam visíveis quando fontes externas falham.

As rotas antigas `/acolhedora`, `/gestao-inteligente` e
`/gestao-inteligente-copia` foram removidas após a ressincronização.
